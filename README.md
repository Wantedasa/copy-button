# Copy Button 📋

Copy any text to the clipboard with a 'Copied!' confirmation. Zero dependencies.

## What it is
A minimal copy-to-clipboard button using the Clipboard API. On success it briefly shows 'Copied!' so the visitor gets feedback. No libraries, works in all modern browsers.

## Usage
```js
copyBtn.addEventListener("click", () => navigator.clipboard.writeText(text));
```
